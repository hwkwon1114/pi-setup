This adaptation substantially rewrites and reduces the upstream methodology for Pi: explicit invocation rather than continuous observation; private records by default; UUID-based optional records rather than numeric shell counters; per-target staged/installed/verified states; permission-denial stop rules; Pi directory delivery rather than compulsory .skill archives; behavior tests and baseline checks. No upstream Python helper was incorporated. No scheduler, activation hook, or automatic self-editing is included.
