# Maintain one evolving review

Read for an update or consolidation. Follow the supplied project contract; an explicit report-only assignment does not authorize project edits. Otherwise, update the existing review in place within the assigned write scope. Use a separate review only for a genuinely separate topic or explicit request.

## Reconcile, then publish

1. Identify the authoritative catalog, current narrative, evidence/index views, bibliography and generation workflow. Historical snapshots are provenance, not the latest catalog. Ask for missing ownership or write scope rather than inventing a competing source.
2. Reconcile retained papers—including new comparators—and affected claims into that model. Preserve stable IDs, original seed mappings, version/source locators, actual access/validation limits, metadata uncertainties and researcher-owned notes. Keep dated reasons for revised claims; do not merely append a competing conclusion or silently upgrade inherited evidence.
3. Refresh the current narrative, paper index/evidence table and bibliography through the existing workflow. Do not strand new papers in an appendix or create a second maintained catalog/export. If generation or rendering belongs to the main assistant, hand back exact source changes and remaining refresh work; do not claim consolidation complete.
4. Keep one reader-facing entry point with raw provenance and necessary historical snapshots behind it. Temporary child reports and private run directories are recovery material, not parallel final reviews. Consolidate/archive non-destructively; do not delete source evidence, runtime artifacts or user files to simplify navigation.
5. Check cross-file IDs/counts, duplicate works/version relationships, seed mappings, citation/bibliography coverage, links and affected rendered navigation. Reconcile stale narrative claims. Record which dependent views were actually refreshed and inspected.

A finished child report is not a finished update. If interrupted or outside the assigned integration scope, mark consolidation incomplete and identify remaining work. No extra searches are needed merely to unify saved material. Structural completion does not establish exhaustive coverage or verify unresolved evidence.
