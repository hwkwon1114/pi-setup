# Evidence-and-decision card

Use for a load-bearing paper or claim when existing notes do not already support the decision. Add it to the current dossier/evidence notes; reuse IDs rather than creating another catalog. Write only meaningful content, not a blank template for every paper.

## Compact format

**Question / claim ID:** What must this source resolve?

**Source:** Paper ID, exact version, URL/local path, actual access and inspected pages/sections; distinguish PDF page index from printed page labels.

**Target and assumptions:** What is estimated, explained or proved? Which assumptions and prior results does it depend on?

| Claim and type | Inspected passage / equation / figure / table | What it supports—and does not |
|---|---|---|

**Challenge:** Closest alternative, counterevidence or broken assumption; cite its source or mark it unresolved. Repeated citations to the same work are not independent support.

**Decision delta:** What changes in our interpretation, claim status or next research choice? Separate source results from inference/proposal and inherited unverified claims. For updates retain the prior wording and reason for the change.

**Next action:** The smallest missing check, reading need or discriminating test. Explicitly mark unread/inaccessible evidence; do not fill unknowns to finish the card.

Use the project's access labels; defaults are in [protocol.md](protocol.md). Existing labels/notes need not trigger a new protocol read or schema migration.

## Only when requested

- **Learning:** Compare the researcher's own explanation with inspected source evidence and record what changed. Do not invent their answer or impose a quiz on an automated update.
- **Writing:** Map proposed claim → nearest work → verified difference → evidence → unresolved objection → argument location. For a key figure, note the supported claim, encoding and what is missing. Hand further project/plot work to an authorized host workflow; no new experiments or skills are enabled by this card.
